# VoiceReader desktop icon

`voicereader-source.png` is the generated master. `icon.ico` (Windows) and
`icon.icns` (macOS) are generated from this same image with the Tauri icon command.
`icon.png` is the PNG preview.

Regenerate with `npx tauri icon src-tauri/icons/voicereader-source.png`.
The macOS configuration explicitly selects `icons/icon.icns`; Windows selects
`icons/icon.ico`.

Generated with the built-in image-generation tool. No model selector was available,
so a specific GPT Image model version is not claimed.
