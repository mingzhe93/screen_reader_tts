VoiceReader files bundled with the app (src-tauri/binaries)

What belongs here depends on the build profile. Only this file and the Windows SoX
files in sox/ are committed. Everything else is generated or downloaded and is
git-ignored (.gitignore lists models/, onnxruntime/, kyutai-voices/ and tts-engine-*).

Folders
-------
models/Verylicious/pocket-tts-ungated/   Both builds. Kyutai Pocket TTS model.
  Generated by `npm run models:bundle:kyutai` (copied from tts-engine/.data/models;
  if that is missing the helper runs tts-engine/scripts/prefetch_models.py with the
  Python of tts-engine/.venv to fill it from Hugging Face). Not committed.
  The app treats the folder as valid only if it contains:
    voicereader-pocket-tts.yaml
    tts_b6369a24.safetensors
    tokenizer.model
    embeddings/alba.safetensors
  The folder also holds the other seven built-in preset voices under embeddings/.

sox/   Both builds. SoX, used for pitch-preserving playback-rate changes and for
  normalizing reference clips when cloning a voice. Committed for Windows
  (sox.exe, its DLLs and licence files). `npm run models:bundle:kyutai` and
  `npm run sidecar:build` replace the folder with the runtime files of the SoX found on
  the build machine (VOICEREADER_SOX_PATH, then PATH, then the Windows winget packages
  folder), so running them on another platform replaces the committed Windows files. If
  no SoX is found they only warn and leave the folder alone. Without SoX at run time
  the rate is changed by resampling, which also changes pitch.

onnxruntime/   Base build only. ONNX Runtime shared library, used by Audio8 TTS and by
  transcription. Fetched by `npm run onnxruntime:fetch` (scripts/fetch-onnxruntime.js).
  Not committed. VERSION.txt records what was fetched (1.24.4, or 1.23.2 on Intel
  macOS; on Windows together with DirectML 1.15.4). Contents by platform:
    Windows:  onnxruntime.dll (DirectML build) and DirectML.dll (x64 and ARM64)
    macOS:    libonnxruntime.dylib (Apple silicon and Intel)
    Linux:    libonnxruntime.so (x64)
  The app loads the library by path, never from the system library path. Set
  VOICEREADER_ONNXRUNTIME_PATH to use a different file.

kyutai-voices/   Base build only. Reference clips (<name>.wav) for the 13 extra
  Kyutai preset voices, plus ATTRIBUTION.txt. Fetched by `npm run kyutai-voices:fetch`
  (scripts/fetch-kyutai-voices.js). Not committed. Without it only the eight built-in
  presets work.

tts-engine-<target triple>/   Full build only. The Python sidecar, built by
  `npm run sidecar:build` (PyInstaller, one folder; the folder also holds a
  .build-profile marker that lets an up-to-date build be skipped). Not committed.
    Windows:        tts-engine-x86_64-pc-windows-msvc/tts-engine.exe
    macOS Intel:    tts-engine-x86_64-apple-darwin/tts-engine
    macOS Arm:      tts-engine-aarch64-apple-darwin/tts-engine
    Linux x86_64:   tts-engine-x86_64-unknown-linux-gnu/tts-engine
  `npm run sidecar:build` also runs the Kyutai model and SoX steps above.

The Audio8 TTS model (about 860 MB) and the transcription models (the multitalker
Parakeet model and the Nemotron-3 diarizer, about 1.07 GB together) are not bundled.
They are downloaded from inside the app into the data directory, under models/.

What each build bundles
-----------------------
Base build (`build-base`), in the installer: src-tauri/tauri.base.conf.json replaces the
  resources with binaries/models, binaries/sox, binaries/onnxruntime and
  binaries/kyutai-voices, and its beforeBuildCommand is `npm run models:bundle:kyutai &&
  npm run build`. The sidecar folder is not bundled.
Full build (`build-full`), in the installer: src-tauri/tauri.conf.json bundles all of
  binaries/ (resources binaries/**/*), including the sidecar folder, and its
  beforeBuildCommand is `npm run sidecar:build && npm run build`.

Portable packages (scripts/package_portable.py, Windows only) copy these next to the
executable:
  Base:  models (required; the package fails without it), then onnxruntime,
         kyutai-voices and sox (each one that exists; a missing folder gives a warning,
         and the package still builds).
  Full:  the whole binaries/ tree.

Commands
--------
Full sidecar build:                  npm run sidecar:build
Bundle Kyutai model and SoX only:    npm run models:bundle:kyutai
Fetch the ONNX Runtime library:      npm run onnxruntime:fetch
Fetch the extra Kyutai voice clips:  npm run kyutai-voices:fetch
Both fetches:                        npm run assets:fetch (runs before Base dev and build)
Base installer:                      npm run desktop:build:base:installer
Base portable package:               npm run desktop:build:base:portable
Full portable package:               npm run desktop:build:full:portable
