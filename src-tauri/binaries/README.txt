VoiceReader files bundled with the app (src-tauri/binaries)

What belongs here depends on the build profile. Most folders are generated or
downloaded and are not committed (see .gitignore).

Folders
-------
models/Verylicious/pocket-tts-ungated/   Both builds. Kyutai Pocket TTS model.
  Generated by `npm run models:bundle:kyutai` (copied from tts-engine/.data/models,
  which the helper fills from Hugging Face if it is missing). Not committed.
  The app treats the folder as valid only if it contains:
    voicereader-pocket-tts.yaml
    tts_b6369a24.safetensors
    tokenizer.model
    embeddings/alba.safetensors
  The folder also holds the other seven built-in preset voices under embeddings/.

sox/   Both builds. SoX, used for pitch-preserving playback-rate changes and for
  normalizing reference clips when cloning a voice. Committed for Windows
  (sox.exe, its DLLs and licence files). `npm run models:bundle:kyutai` replaces the
  folder with the runtime files of the SoX found on the build machine
  (VOICEREADER_SOX_PATH, then PATH, then the Windows winget packages folder). If
  none is found it only warns and leaves the folder alone. Without SoX at run time
  the rate is changed by resampling, which also changes pitch.

onnxruntime/   Base build only. ONNX Runtime shared library for Audio8 TTS.
  Fetched by `npm run onnxruntime:fetch`. Not committed. VERSION.txt records what was
  fetched. Contents by platform:
    Windows:  onnxruntime.dll (DirectML build) and DirectML.dll
    macOS:    libonnxruntime.dylib
    Linux:    libonnxruntime.so (x64)
  The app loads the library by path, never from the system library path. Set
  VOICEREADER_ONNXRUNTIME_PATH to use a different file.

kyutai-voices/   Base build only. Reference clips (<name>.wav) for the 13 extra
  Kyutai preset voices, plus ATTRIBUTION.txt. Fetched by `npm run kyutai-voices:fetch`.
  Not committed. Without it only the eight built-in presets work.

tts-engine-<target triple>/   Full build only. The Python sidecar, built by
  `npm run sidecar:build` (PyInstaller, one folder). Not committed.
    Windows:        tts-engine-x86_64-pc-windows-msvc/tts-engine.exe
    macOS Intel:    tts-engine-x86_64-apple-darwin/tts-engine
    macOS Arm:      tts-engine-aarch64-apple-darwin/tts-engine
    Linux x86_64:   tts-engine-x86_64-unknown-linux-gnu/tts-engine

The Audio8 TTS model is not bundled. It is downloaded from inside the app into the
data directory.

What each build bundles
-----------------------
Base build (`build-base`), in the installer: src-tauri/tauri.base.conf.json lists
  binaries/models, binaries/sox, binaries/onnxruntime and binaries/kyutai-voices.
Full build (`build-full`), in the installer: src-tauri/tauri.conf.json bundles all of
  binaries/, including the sidecar folder.

Portable packages (scripts/package_portable.py) copy these next to the executable:
  Base:  models, onnxruntime, kyutai-voices and sox (each one that exists; a missing
         folder gives a warning, and the package still builds).
  Full:  the whole binaries/ tree.

Commands
--------
Full sidecar build:                  npm run sidecar:build
Bundle Kyutai model and SoX only:    npm run models:bundle:kyutai
Fetch the ONNX Runtime library:      npm run onnxruntime:fetch
Fetch the extra Kyutai voice clips:  npm run kyutai-voices:fetch
Both fetches:                        npm run assets:fetch (runs before Base dev and build)
Base portable package:               npm run desktop:build:base:portable
Full portable package:               npm run desktop:build:full:portable
